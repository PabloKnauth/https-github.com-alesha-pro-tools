# Kit de Claude para Kevin Juárez (ROJU Consulting)

Preparado por Pablo para que su socio tenga en su propia cuenta y su propio repositorio las mismas
skills y herramientas. Las instrucciones completas están en el documento de traspaso que Pablo le compartió.

| Carpeta o archivo | Qué es |
|---|---|
| `skills-cuenta/` | Las 8 skills propias de Pablo, en texto, para revisarlas o recrearlas |
| `skills-cuenta-zip/` | Las mismas 8 skills, una por ZIP, para subirlas en claude.ai → Ajustes → Skills |
| `plantilla/` | Archivos base para el repositorio de Kevin (`_claude/` se copia como `.claude/`) |
| `instalar.sh` | Copia todo al repositorio de Kevin e instala Graphify y Ponytail |

Uso, desde la raíz del repositorio de Kevin:

```bash
bash <ruta-al-clon-de-Pablo>/kit-socio-roju/instalar.sh <ruta-al-clon-de-Pablo>
```

El kit no contiene claves ni contraseñas: Kevin usa las suyas.
