# Estándares de diseño editorial para manuales

## Legibilidad
- Tipo de letra adecuado al cuerpo y al medio; preferir consistencia a variedad.
- Jerarquías distinguibles por tamaño, peso y ubicación, no exclusivamente color.
- Contraste suficiente en títulos, cuerpo, tablas y llamadas; considerar accesibilidad visual.
- Líneas y párrafos de extensión razonable; aire visual suficiente.
- Índice y encabezados útiles para búsqueda rápida; paginación verificable.
- Evitar bloques demasiado densos, fondos recargados y tablas imposibles de leer.

## Diagramas
- Todas las ramas de decisión deben tener criterios confirmados.
- Señales de inicio/fin, responsables y direcciones inequívocas.
- Si el diagrama agrega o elimina un paso frente al texto oficial, bloquear el cierre hasta corregirlo.

## Portada
- Identidad corporativa auténtica y sin distorsiones.
- Título y audiencia inequívocos.
- Versión, fecha y clasificación solo con datos confirmados.
- Ningún logo tocando texto ni fuera del área segura.

## QA de página
- [ ] Texto, datos y tablas sin recortes ni elementos superpuestos.
- [ ] Logos y fotografías legítimos y legibles.
- [ ] Numeración, índice y referencias coinciden.
- [ ] Contraste y jerarquía coherentes en todas las páginas.
- [ ] Tablas extensas tienen encabezados repetidos cuando aplica.
- [ ] Notas, anexos y advertencias no desaparecieron.
- [ ] Documento visualmente revisado en el formato de entrega.

## Si el contenido es intocable
- Conservar archivo fuente intacto.
- Si es posible, comparar exportaciones de texto extraído del original y el rediseño por títulos, secciones, párrafos, tablas, números y advertencias.
- Diferencias de extracción en PDF requieren **revisión manual**; nunca afirmar igualdad absoluta con una comparación incompleta.
- Informar: «Cambios: únicamente diseño» solo si se verificó. De otro modo: «El objetivo fue preservar todo el contenido; pendiente cotejo completo».
